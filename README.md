# Stramuntana Gaia — Website

Website one-page responsivo criado para apresentação/demonstração.

## Publicar gratuitamente

### Netlify
1. Aceda a https://app.netlify.com/drop
2. Arraste a pasta `stramuntana-gaia` para a área indicada.
3. O site ficará disponível num endereço gratuito `netlify.app`.

### GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. Ative GitHub Pages nas definições do repositório.

## Antes de apresentar ao restaurante
Substituir:
- imagens de demonstração por fotografias autorizadas do restaurante;
- texto institucional pelo texto oficial;
- pratos/preços pelo menu real;
- `[Inserir horários oficiais]` pelos horários confirmados.

O telefone e Instagram já estão configurados conforme os dados fornecidos.
